🔢 Algebra

Algebra uses letters and symbols to represent numbers and relationships.

1. Laws of exponents

aᵐ × aⁿ = aᵐ⁺ⁿ

aᵐ ÷ aⁿ = aᵐ⁻ⁿ, a ≠ 0

(aᵐ)ⁿ = aᵐⁿ

a⁰ = 1, a ≠ 0

a⁻ⁿ = 1/aⁿ, a ≠ 0

Example: Simplify x³ × x⁵ = x⁸.

2. Surds

Surds are irrational roots that cannot be simplified to rational numbers.

√50 = √(25 × 2) = 5√2.

3. Quadratic equations

ax² + bx + c = 0

x = (-b ± √(b² - 4ac))/(2a)

Solve x² - 5x + 6 = 0.
(x - 2)(x - 3) = 0
x = 2 or x = 3.

4. Discriminant

Δ = b² - 4ac

  • Δ > 0: two distinct real roots.
  • Δ = 0: two equal real roots.
  • Δ < 0: no real roots.

5. Equations and inequalities

Whatever operation is performed on one side of an equation must also be performed on the other side.

When multiplying or dividing an inequality by a negative number, reverse the inequality sign.

6. Simultaneous equations

If x + y = 7 and x - y = 1, adding the equations gives 2x = 8. Therefore x = 4 and y = 3.

7. Algebraic fractions

Factorise first, then cancel common factors. A denominator cannot equal zero.

(x² - 9)/(x - 3) = ((x - 3)(x + 3))/(x - 3) = x + 3, where x ≠ 3.

8. Exam tips

  • Show all working.
  • Check solutions in the original equation.
  • State restrictions for algebraic fractions and square roots.

📘 Sequences and Series

Sequence: an ordered list of numbers following a pattern. Series: the sum of terms in a sequence.

1. Arithmetic sequences

The difference between consecutive terms is constant.

Tₙ = a + (n - 1)d

Sₙ = n/2 [2a + (n - 1)d]

Sₙ = n/2 (a + l)

a = first term, d = common difference, n = number of terms, l = last term.

Example: 3, 7, 11, 15, ...
a = 3 and d = 4.
T₁₀ = 3 + 9(4) = 39.

2. Geometric sequences

The ratio between consecutive non-zero terms is constant.

Tₙ = arⁿ⁻¹

Sₙ = a(rⁿ - 1)/(r - 1), r ≠ 1

S∞ = a/(1 - r), when |r| < 1

Example: 2, 6, 18, 54, ...
a = 2 and r = 3.
T₅ = 2(3⁴) = 162.

3. Arithmetic versus geometric

4. Sigma notation

Σ from k=1 to n of k = n(n + 1)/2

1 + 2 + 3 + 4 + 5 = 5(6)/2 = 15.

5. Exam tips

  • Identify whether the pattern uses a difference or a ratio.
  • Write down a, d or r before substituting.
  • For an infinite geometric series, check that |r| < 1.

📈 Functions and Graphs

This chapter covers function notation, domains and ranges, graph transformations, parabolas, hyperbolas, inverse functions, logarithms and exponential functions.

1. What is a function?

A function assigns exactly one output to each permitted input. We often write y = f(x).
  • Domain: all permitted input values (x-values).
  • Range: all possible output values (y-values).
  • x-intercept: where the graph crosses or touches the x-axis; set y = 0.
  • y-intercept: where the graph crosses the y-axis; set x = 0.
Example: If f(x) = 2x + 3, then f(4) = 2(4) + 3 = 11.
The vertical-line test checks whether a graph represents a function: every vertical line must intersect it at most once.

2. The parabola: quadratic functions

y = a(x - p)² + q, a ≠ 0

Turning point: (p, q). Axis of symmetry: x = p.

  • If a > 0, the parabola opens upwards and has a minimum.
  • If a < 0, it opens downwards and has a maximum.
  • The absolute value of a affects the width of the graph.
Example: y = (x - 2)² - 3 has turning point (2, -3), axis x = 2, minimum y = -3 and range y ≥ -3.

Finding the intercepts

For y = x² - 5x + 6, set y = 0:
x² - 5x + 6 = 0
(x - 2)(x - 3) = 0
x-intercepts: (2, 0) and (3, 0).
Set x = 0 to find the y-intercept: y = 6, so (0, 6).

3. Hyperbolic functions

y = a/(x - p) + q, a ≠ 0

Vertical asymptote: x = p.

Horizontal asymptote: y = q.

Centre: (p, q).

The domain excludes x = p and the range excludes y = q, when a ≠ 0.

Example: y = 2/(x - 1) + 3 has vertical asymptote x = 1, horizontal asymptote y = 3 and centre (1, 3).
An asymptote is a line that the graph approaches. The graph does not cross either asymptote for this basic translated hyperbola.

4. Exponential functions

y = ab^(x - p) + q, b > 0, b ≠ 1

Horizontal asymptote: y = q.

  • For b > 1, the basic function bˣ shows exponential growth.
  • For 0 < b < 1, the basic function bˣ shows exponential decay.
  • For y = abˣ + q, if a > 0, the range is y > q; if a < 0, the range is y < q.
Example: y = 2ˣ has domain all real numbers, range y > 0, y-intercept (0, 1), and horizontal asymptote y = 0.

6. Inverse functions: general properties

An inverse function reverses the action of the original function. It is written as f⁻¹(x). The notation f⁻¹(x) does not mean 1/f(x).

To find an inverse algebraically:

  1. Write y = f(x).
  2. Swap x and y.
  3. Solve for y.
  4. Write the result as y = f⁻¹(x).
  • The domain of the inverse is the range of the original function.
  • The range of the inverse is the domain of the original function.
  • The graphs of f and f⁻¹ are reflections of one another in the line y = x.
  • A function must be one-to-one on its domain to have an inverse that is also a function.
The horizontal-line test checks whether a function is one-to-one: every horizontal line must intersect its graph at most once.

7. Inverse of a straight-line function

Question: Find the inverse of f(x) = 2x + 3.

Step 1: y = 2x + 3
Step 2: Swap x and y: x = 2y + 3
Step 3: x - 3 = 2y
y = (x - 3)/2
Answer: f⁻¹(x) = (x - 3)/2.

Check: f(f⁻¹(x)) = 2((x - 3)/2) + 3 = x.

8. Inverse of a quadratic function

A full parabola is not one-to-one over all real x-values. You must restrict its domain before defining its inverse as a function.
Question: Find the inverse of f(x) = (x - 1)² + 2, given x ≥ 1.

Step 1: y = (x - 1)² + 2
Step 2: Swap x and y: x = (y - 1)² + 2
Step 3: x - 2 = (y - 1)²
y - 1 = ±√(x - 2)

Because the original domain is x ≥ 1, choose the positive branch:
f⁻¹(x) = 1 + √(x - 2).

The original function has range y ≥ 2, so the inverse has domain x ≥ 2. Its range is y ≥ 1.

If the original quadratic domain is restricted to x ≤ 1 instead, the inverse branch is y = 1 - √(x - 2).

9. Inverse of an exponential function

Question: Find the inverse of f(x) = 2ˣ.

y = 2ˣ
Swap x and y: x = 2ʸ
Rewrite in logarithmic form: y = log₂x
Answer: f⁻¹(x) = log₂x.

The graphs y = 2ˣ and y = log₂x are reflections across y = x. The exponential horizontal asymptote y = 0 corresponds to the logarithmic vertical asymptote x = 0.

10. Logarithmic functions

logₐx = y means aʸ = x, where a > 0, a ≠ 1 and x > 0.
  • The domain of y = logₐx is x > 0.
  • The range is all real numbers.
  • The vertical asymptote is x = 0.
  • If a > 1, the graph increases.
  • If 0 < a < 1, the graph decreases.
Example: log₂8 = 3 because 2³ = 8.
Also, log₁₀100 = 2 because 10² = 100.

11. Logarithm laws

logₐ(MN) = logₐM + logₐN

logₐ(M/N) = logₐM - logₐN

logₐ(Mᵏ) = k logₐM

logₐ1 = 0

logₐa = 1

logₐx = logᵦx / logᵦa

The last formula is the change-of-base rule. For real logarithms, the arguments M, N and x must be positive, and the base must be positive and not equal to 1.

Example 1: log₂(8 × 4) = log₂8 + log₂4 = 3 + 2 = 5.
Example 2: log₃(x²) = 2log₃x for x > 0.
Example 3: log₅25 = 2 because 5² = 25.
You cannot split log(M + N) into log M + log N. The product law applies to multiplication, not addition.

12. Solving exponential and logarithmic equations

Exponential example: Solve 2ˣ = 16.
Since 16 = 2⁴, x = 4.

Logarithmic example: Solve log₃x = 2.
Rewrite in exponential form: x = 3² = 9.
When the bases are the same, compare the exponents. When using logarithms, always check that logarithm arguments are positive.

13. Intersections of graphs

At an intersection, the two functions have the same x-value and y-value. Set their equations equal and solve.

Find where y = x + 1 and y = 5 meet.
x + 1 = 5, so x = 4. The intersection is (4, 5).

14. Graph-sketching checklist

  1. Identify the type of function.
  2. Find intercepts where possible.
  3. Calculate the turning point or centre when applicable.
  4. Identify asymptotes.
  5. State the domain and range.
  6. Plot enough points to show the shape.
  7. Label axes, intercepts, turning points and asymptotes.

💰 Finance, Growth and Decay

1. Simple interest

I = Pin

A = P(1 + in)

P = principal, i = interest rate per period, n = number of periods, I = interest, A = final amount.

2. Compound interest

A = P(1 + i)ⁿ

R1 000 is invested at 10% per year, compounded annually, for 2 years.
A = 1000(1.10)² = R1 210.

3. Depreciation

A = P(1 - i)ⁿ

This formula models reducing-balance depreciation when the value decreases by a fixed percentage each period.

4. Annuities

An annuity involves regular payments or deposits. Use the formula specified in the question and identify whether payments occur at the beginning or end of each period.

Make sure the interest rate and time period use matching units. For monthly calculations, convert the annual rate and number of periods as instructed.

📉 Differential Calculus

Differentiation finds the gradient of a curve at a point and helps determine stationary points.

1. Power rule

If y = axⁿ, then dy/dx = anxⁿ⁻¹

If y = 3x² + 4x - 5, then dy/dx = 6x + 4.

2. Gradient at a point

Substitute the required x-value into the derivative to find the gradient at that point.

For y = x², dy/dx = 2x. At x = 3, the gradient is 6.

3. Stationary points

At a stationary point, dy/dx = 0. Solve this equation to find the x-coordinates, then substitute into the original function to find y.

For y = x² - 4x + 1:
dy/dx = 2x - 4.
Set 2x - 4 = 0, so x = 2.
y = 4 - 8 + 1 = -3.
Stationary point: (2, -3).

4. Nature of stationary points

  • For a parabola opening upwards, its turning point is a minimum.
  • For a parabola opening downwards, its turning point is a maximum.
In optimisation questions, define the variable, form the function, differentiate, set the derivative equal to zero and interpret the result in context.

🎲 Probability

Probability measures how likely an event is to occur. Its value is between 0 and 1.

P(A) = favourable outcomes / equally likely possible outcomes

P(A') = 1 - P(A)

1. Addition rule

P(A ∪ B) = P(A) + P(B) - P(A ∩ B)

If A and B are mutually exclusive, P(A ∩ B) = 0.

2. Multiplication rule

P(A ∩ B) = P(A) × P(B|A)

For independent events, P(B|A) = P(B), so P(A ∩ B) = P(A)P(B).

3. Example

A fair six-sided die is rolled.

P(rolling a 4) = 1/6.
P(not rolling a 4) = 1 - 1/6 = 5/6.

4. Two-way tables and tree diagrams

Use tables to organise information and tree diagrams to represent successive events. Multiply probabilities along a branch and add probabilities for separate branches that satisfy the event.

Check whether events are independent, dependent, mutually exclusive or overlapping before choosing a formula.

📊 Statistics

1. Mean

Mean = sum of observations / number of observations

For 2, 4, 6, 8: mean = (2 + 4 + 6 + 8)/4 = 5.

2. Median and mode

  • Median: middle value after arranging data in order. For an even number of observations, average the two middle values.
  • Mode: most frequently occurring value.
  • Range: maximum minus minimum.

3. Standard deviation

Standard deviation describes how spread out data values are around their mean. A larger standard deviation indicates greater spread.

4. Scatter plots and regression

A scatter plot displays paired data. Correlation describes the strength and direction of a linear relationship.

  • Positive correlation: as one variable increases, the other tends to increase.
  • Negative correlation: as one increases, the other tends to decrease.
  • Correlation does not by itself prove causation.
Use the calculator mode required by your examination, and interpret statistical results in the context of the question.

📍 Analytical Geometry

1. Gradient

m = (y₂ - y₁)/(x₂ - x₁)

2. Distance

d = √[(x₂ - x₁)² + (y₂ - y₁)²]

3. Midpoint

M = ((x₁ + x₂)/2, (y₁ + y₂)/2)

4. Equation of a straight line

y - y₁ = m(x - x₁)

For points (1, 2) and (3, 6), the gradient is (6 - 2)/(3 - 1) = 2.

5. Parallel and perpendicular lines

  • Parallel lines have equal gradients.
  • For non-vertical perpendicular lines, m₁m₂ = -1.

6. Circle geometry in coordinates

For a circle with centre (a, b) and radius r:

(x - a)² + (y - b)² = r²

📐 Trigonometry

1. Fundamental identity

sin²θ + cos²θ = 1

tanθ = sinθ/cosθ, where cosθ ≠ 0

2. Other identities

1 + tan²θ = 1/cos²θ

sin(90° - θ) = cosθ

cos(90° - θ) = sinθ

3. Reduction formulae

Use the reference angle and quadrant signs to simplify trigonometric expressions.

ASTC helps determine signs by quadrant: all positive in quadrant I, sine in II, tangent in III and cosine in IV.

Find the reference angle, determine all quadrants that satisfy the sign, and list every solution in the given interval.

For sin θ = 1/2, where 0° ≤ θ ≤ 360°, θ = 30° or 150°.

cos 2θ = cos²θ - sin²θ

△ Euclidean Geometry

1. Angles in a triangle

  • The interior angles of a triangle add to 180°.
  • An exterior angle equals the sum of the two opposite interior angles.

2. Similar and congruent triangles

Congruent triangles have the same shape and size. Similar triangles have equal corresponding angles and proportional corresponding sides.

3. Circle theorems

  • The angle at the centre is twice the angle at the circumference subtended by the same arc.
  • Angles in the same segment are equal.
  • The angle in a semicircle is 90°.
  • Opposite angles of a cyclic quadrilateral add to 180°.
  • A tangent is perpendicular to the radius at the point of contact.
  • Tangents drawn from the same external point have equal lengths.

4. Writing geometric proofs

  1. State the geometric fact or theorem.
  2. Identify the relevant angles or lengths.
  3. Show each deduction clearly.
  4. Give a reason for every important step.
Do not write only a final answer. In proof questions, the reasons are an important part of your marks.
