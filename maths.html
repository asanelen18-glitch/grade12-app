1. Algebraic expressions and like terms

An algebraic expression contains numbers, variables and operations.

Variable: a letter representing a number.

Coefficient: the number multiplying a variable.

Constant: a number without a variable.

Term: a part separated by plus or minus signs.

Simplify 4x + 3x − 2 + 5.

Combine like terms only. For example, 2x and 3x² are unlike terms.

3. Arithmetic sequences: general term

An arithmetic sequence has a constant difference between consecutive terms.
Tₙ = a + (n − 1)d

Proof of the arithmetic general-term formula

The terms are:
T₁ = a
T₂ = a + d
T₃ = a + 2d
T₄ = a + 3d
Each new term adds one more common difference. To reach term n, there are n − 1 differences.
Therefore, Tₙ = a + (n − 1)d
Find the 20th term of 4, 9, 14, 19, …

a = 4, d = 5, n = 20.

T₂₀ = 4 + (20 − 1)(5) = 99
Which term of 7, 11, 15, 19, … is 63?
63 = 7 + (n − 1)4
56 = 4(n − 1)
14 = n − 1 → n = 15

4. Last term of an arithmetic sequence

If the sequence has n terms, the last term is Tₙ, often represented by l.
l = a + (n − 1)d
Find the last term if a = 5, d = 3 and n = 12.
l = 5 + (12 − 1)(3) = 38
If you know the first term, common difference and number of terms, use the last-term formula. If you know the last term, you can use it to find n.

5. Arithmetic series: sum of n terms

An arithmetic series is the sum of terms from an arithmetic sequence.
Sₙ = n/2 (a + l)
Sₙ = n/2 [2a + (n − 1)d]

Proof of the arithmetic sum formula

Write the series forwards:
Sₙ = a + (a + d) + … + l
Write it backwards:
Sₙ = l + (l − d) + … + a
Add the two lines. Every pair adds to a + l, and there are n pairs:
2Sₙ = n(a + l)
Divide both sides by 2:
Sₙ = n(a + l)/2
Since l = a + (n − 1)d, substituting gives:
Sₙ = n/2 [2a + (n − 1)d]
Find the sum of the first 10 terms of 2, 5, 8, 11, …
a = 2, d = 3, n = 10
S₁₀ = 10/2 [2(2) + 9(3)]
= 5(4 + 27) = 155
Find the sum of 5 + 8 + 11 + … + 35.
35 = 5 + (n − 1)3
30 = 3(n − 1) → n = 11
S₁₁ = 11/2 (5 + 35) = 220

6. Geometric sequences: general term

A geometric sequence has a constant ratio between consecutive non-zero terms.
Tₙ = arⁿ⁻¹

Proof of the geometric general-term formula

T₁ = a
T₂ = ar
T₃ = ar²
T₄ = ar³
The exponent is one less than the term number, so:
Tₙ = arⁿ⁻¹
Find the sixth term of 2, 6, 18, 54, …
a = 2, r = 3
T₆ = 2(3)⁵ = 486
Find the general term of 80, 40, 20, 10, …
a = 80, r = ½
Tₙ = 80(½)ⁿ⁻¹

7. Finite geometric series: sum of n terms

For r ≠ 1, the sum of the first n terms is:
Sₙ = a(rⁿ − 1)/(r − 1)
An equivalent form is:
Sₙ = a(1 − rⁿ)/(1 − r)

Proof of the geometric sum formula

Start with:
Sₙ = a + ar + ar² + … + arⁿ⁻¹
Multiply by r:
rSₙ = ar + ar² + … + arⁿ
Subtract the second equation from the first:
Sₙ − rSₙ = a − arⁿ
Factorise:
Sₙ(1 − r) = a(1 − rⁿ)
Divide by 1 − r:
Sₙ = a(1 − rⁿ)/(1 − r)
Find the sum of the first four terms of 2, 6, 18, 54, …
S₄ = 2(3⁴ − 1)/(3 − 1)
= 2(80)/2 = 80
When r = 1, every term is a. The sum is then Sₙ = na.

8. Sum to infinity

A geometric series has a finite sum to infinity only when |r| < 1.
S∞ = a/(1 − r)
This condition means that the terms get closer to zero as n increases.
Find the sum to infinity of 12 + 6 + 3 + 1.5 + …
a = 12, r = ½
S∞ = 12/(1 − ½) = 24
Find the sum to infinity of 9 − 3 + 1 − ⅓ + …
a = 9, r = −⅓
S∞ = 9/[1 − (−⅓)] = 9/(4/3) = 27/4
Do not use the sum-to-infinity formula when |r| ≥ 1. The series does not converge to a finite sum.

10. Sigma notation (Σ)

Sigma notation is a compact way of writing a sum. The symbol Σ means that the expression should be added over a range of index values.
Σ from k = 1 to n of aₖ
  • k: the index variable.
  • 1: the starting value of the index.
  • n: the ending value of the index.
  • aₖ: the expression being added.

Expanding sigma notation

Σ from k = 1 to 5 of k
Expand:
1 + 2 + 3 + 4 + 5 = 15
Σ from k = 1 to 4 of (2k + 1)
Substitute k = 1, 2, 3, 4:
3 + 5 + 7 + 9 = 24

Writing a sum in sigma notation

Write 2 + 4 + 6 + 8 + 10 in sigma notation.
Σ from k = 1 to 5 of 2k
Calculate the sum of the first four terms of the sequence defined by Tₖ = k².
Σ from k = 1 to 4 of k²
= 1² + 2² + 3² + 4² = 30
Always check the starting index and ending index. If the index starts at 0, the first substitution must use 0.

11. Exam tips and common mistakes

  • Do not confuse common difference d with common ratio r.
  • Remember the n − 1 in the general-term formulas.
  • Use Tₙ for a single term and Sₙ for a sum.
  • Find the number of terms before using a sum formula if n is not given.
  • Use the correct last term in Sₙ = n(a + l)/2.
  • Check |r| < 1 before calculating a sum to infinity.
  • For sigma notation, substitute every index value, including the endpoints.
  • Show your proof steps rather than writing only the final formula.

What is a function?

A function assigns exactly one output to each allowed input.

Input x
↓
Apply the function rule
↓
Output y = f(x)

If f(x) = 2x + 1, then f(3) = 2(3) + 1 = 7.

3. Straight-line graphs

The general equation is:
y = mx + c

m is the gradient and c is the y-intercept. A positive gradient rises from left to right; a negative gradient falls.

Gradient between two points

Finding intercepts

4. Parabolas (quadratic functions)

A quadratic function has the form y = ax² + bx + c, where a ≠ 0.
  • a > 0: opens upwards.
  • a < 0: opens downwards.
  • Axis of symmetry: x = −b/(2a).
  • The turning point lies on the axis of symmetry.

Graph A: Opens upwards

Example: y = x²

Turning point (0, 0); minimum value is 0.

Graph B: Opens downwards

Example: y = −x²

Turning point (0, 0); maximum value is 0.

Turning point and intercepts

Find the turning point of y = x² − 4x + 3.
x = −b/(2a) = −(−4)/(2) = 2
y = 2² − 4(2) + 3 = −1

Turning point: (2, −1). Axis of symmetry: x = 2. The parabola opens upwards.

Find the x-intercepts of y = x² − 4x + 3.
0 = x² − 4x + 3 = (x − 1)(x − 3)
x = 1 or x = 3

Intercepts: (1, 0) and (3, 0).

For y = (x − 2)² − 1, the turning point is (2, −1). Since it opens upwards, its range is y ≥ −1.

5. Hyperbolas

A common Grade 12 hyperbola is:
y = a/(x − p) + q

Vertical asymptote: x = p. Horizontal asymptote: y = q. Centre: (p, q). Domain: x ≠ p. Range: y ≠ q.

Graph A: Positive reciprocal

Example: y = 1/x

Branches in quadrants I and III.

Graph B: Negative reciprocal

Example: y = −1/x

Branches in quadrants II and IV.

For y = 6/x + 2:
  • Vertical asymptote: x = 0.
  • Horizontal asymptote: y = 2.
  • At x = 3, y = 4, so (3, 4) is on the graph.
  • For the x-intercept: 0 = 6/x + 2, so x = −3.
  • There is no y-intercept because x cannot be 0.

9. Inverse functions

An inverse function reverses the input-output process. The inverse is written f⁻¹(x). It is not the same as 1/f(x).

How to find an inverse

Write y = f(x).
↓
Swap x and y.
↓
Solve for y.
↓
Write y = f⁻¹(x).
Example 1: Find the inverse of f(x) = 2x + 1.
y = 2x + 1

Swap x and y:

x = 2y + 1
y = (x − 1)/2

Therefore:

f⁻¹(x) = (x − 1)/2
Example 2: Find the inverse of f(x) = x², given x ≥ 0.
y = x²

Swap x and y:

x = y²

Since the original domain is x ≥ 0, choose the non-negative square root:

f⁻¹(x) = √x

Original function

f(x) = 2x + 1

Inverse function

f⁻¹(x) = (x − 1)/2

The horizontal line test

A function has an inverse that is also a function if every horizontal line intersects its graph at most once. If it fails, restrict the original domain before finding the inverse.
For y = x² over all real x, the inverse relation is y = ±√x, which is not a function. Restricting the original domain to x ≥ 0 gives f⁻¹(x) = √x.

Finance, Growth and Decay

Compound interest is calculated on the original amount and on interest already accumulated.
A = P(1 + i)ⁿ
  • A = accumulated amount
  • P = initial amount or principal
  • i = interest rate per period as a decimal
  • n = number of periods
R1 000 invested at 10% per year for 2 years: A = 1 000(1.10)² = R1 210.
Convert 8% to 0.08 before substituting. Match the interest rate and number of periods.

Differential Calculus

A derivative measures the instantaneous rate of change of a function and gives the gradient of the tangent.
If y = xⁿ, then dy/dx = nxⁿ⁻¹
y = 3x² + 4x − 1 → dy/dx = 6x + 4.
  • Differentiate powers of x.
  • Find stationary points by setting dy/dx = 0.
  • Use the original function to calculate the y-coordinate.
  • Determine whether a stationary point is a maximum or minimum.
The derivative of a constant is zero.

Probability

Probability measures how likely an event is to occur. 0 means impossible; 1 means certain.
P(A) = favourable outcomes / total equally likely outcomes
For a fair six-sided die, P(rolling a 4) = 1/6.
  • Complement: P(not A) = 1 − P(A).
  • Mutually exclusive events cannot occur together.
  • Independent events do not change each other's probabilities.
Check whether outcomes are equally likely before using the simple fraction formula.

Statistics

Statistics involves collecting, organising, analysing and interpreting data.
  • Mean: sum of observations ÷ number of observations.
  • Median: middle observation after arranging data in order.
  • Mode: most frequent value.
  • Range: maximum − minimum.
  • Quartiles: values dividing ordered data into four parts.
  • Standard deviation: measures spread around the mean.
Arrange data in ascending order before finding the median or quartiles.

Analytical Geometry

Analytical geometry uses coordinates and algebra to investigate geometric relationships.
Gradient: m = (y₂ − y₁)/(x₂ − x₁)
Distance: AB = √[(x₂ − x₁)² + (y₂ − y₁)²]
Midpoint: M = ((x₁ + x₂)/2, (y₁ + y₂)/2)
Subtract coordinates in the same order in the numerator and denominator when calculating a gradient.

Trigonometry

Trigonometry studies relationships between angles and trigonometric ratios.
sin²θ + cos²θ = 1
tan θ = sin θ / cos θ, when cos θ ≠ 0
sin(A ± B) = sin A cos B ± cos A sin B
Check the specified interval when solving trigonometric equations.
