1. Algebraic expressions and like terms

An algebraic expression contains numbers, variables and operations.

Variable: a letter representing a number.

Coefficient: the number multiplying a variable.

Constant: a number without a variable.

Term: a part separated by plus or minus signs.

3. Arithmetic sequences: general term

An arithmetic sequence has a constant difference between consecutive terms.
Tₙ = a + (n − 1)d

Proof of the arithmetic general-term formula

The terms are:
T₁ = a
T₂ = a + d
T₃ = a + 2d
T₄ = a + 3d
Each new term adds one more common difference. To reach term n, there are n − 1 differences.
Therefore, Tₙ = a + (n − 1)d
Find the 20th term of 4, 9, 14, 19, …

a = 4, d = 5, n = 20.

T₂₀ = 4 + (20 − 1)(5) = 99
Which term of 7, 11, 15, 19, … is 63?
63 = 7 + (n − 1)4
56 = 4(n − 1)
14 = n − 1 → n = 15

4. Last term of an arithmetic sequence

If the sequence has n terms, the last term is Tₙ, often represented by l.
l = a + (n − 1)d
Find the last term if a = 5, d = 3 and n = 12.
l = 5 + (12 − 1)(3) = 38
If you know the first term, common difference and number of terms, use the last-term formula. If you know the last term, you can use it to find n.

5. Arithmetic series: sum of n terms

An arithmetic series is the sum of terms from an arithmetic sequence.
Sₙ = n/2 (a + l)
Sₙ = n/2 [2a + (n − 1)d]

Proof of the arithmetic sum formula

Write the series forwards:
Sₙ = a + (a + d) + … + l
Write it backwards:
Sₙ = l + (l − d) + … + a
Add the two lines. Every pair adds to a + l, and there are n pairs:
2Sₙ = n(a + l)
Divide both sides by 2:
Sₙ = n(a + l)/2
Since l = a + (n − 1)d, substituting gives:
Sₙ = n/2 [2a + (n − 1)d]
Find the sum of the first 10 terms of 2, 5, 8, 11, …
a = 2, d = 3, n = 10
S₁₀ = 10/2 [2(2) + 9(3)]
= 5(4 + 27) = 155
Find the sum of 5 + 8 + 11 + … + 35.
35 = 5 + (n − 1)3
30 = 3(n − 1) → n = 11
S₁₁ = 11/2 (5 + 35) = 220

6. Geometric sequences: general term

A geometric sequence has a constant ratio between consecutive non-zero terms.
Tₙ = arⁿ⁻¹

Proof of the geometric general-term formula

T₁ = a
T₂ = ar
T₃ = ar²
T₄ = ar³
The exponent is one less than the term number, so:
Tₙ = arⁿ⁻¹
Find the sixth term of 2, 6, 18, 54, …
a = 2, r = 3
T₆ = 2(3)⁵ = 486
Find the general term of 80, 40, 20, 10, …
a = 80, r = ½
Tₙ = 80(½)ⁿ⁻¹

7. Finite geometric series: sum of n terms

For r ≠ 1, the sum of the first n terms is:
Sₙ = a(rⁿ − 1)/(r − 1)
An equivalent form is:
Sₙ = a(1 − rⁿ)/(1 − r)

Proof of the geometric sum formula

Start with:
Sₙ = a + ar + ar² + … + arⁿ⁻¹
Multiply by r:
rSₙ = ar + ar² + … + arⁿ
Subtract the second equation from the first:
Sₙ − rSₙ = a − arⁿ
Factorise:
Sₙ(1 − r) = a(1 − rⁿ)
Divide by 1 − r:
Sₙ = a(1 − rⁿ)/(1 − r)
Find the sum of the first four terms of 2, 6, 18, 54, …
S₄ = 2(3⁴ − 1)/(3 − 1)
= 2(80)/2 = 80
When r = 1, every term is a. The sum is then Sₙ = na.

8. Sum to infinity

A geometric series has a finite sum to infinity only when |r| < 1.
S∞ = a/(1 − r)
This condition means that the terms get closer to zero as n increases.
Find the sum to infinity of 12 + 6 + 3 + 1.5 + …
a = 12, r = ½
S∞ = 12/(1 − ½) = 24
Find the sum to infinity of 9 − 3 + 1 − ⅓ + …
a = 9, r = −⅓
S∞ = 9/[1 − (−⅓)] = 9/(4/3) = 27/4
Do not use the sum-to-infinity formula when |r| ≥ 1. The series does not converge to a finite sum.

10. Sigma notation (Σ)

Sigma notation is a compact way of writing a sum. The symbol Σ means that the expression should be added over a range of index values.
Σ from k = 1 to n of aₖ
  • k: the index variable.
  • 1: the starting value of the index.
  • n: the ending value of the index.
  • aₖ: the expression being added.

Expanding sigma notation

Σ from k = 1 to 5 of k
Expand:
1 + 2 + 3 + 4 + 5 = 15
Σ from k = 1 to 4 of (2k + 1)
Substitute k = 1, 2, 3, 4:
3 + 5 + 7 + 9 = 24

Writing a sum in sigma notation

Write 2 + 4 + 6 + 8 + 10 in sigma notation.
Σ from k = 1 to 5 of 2k
Calculate the sum of the first four terms of the sequence defined by Tₖ = k².
Σ from k = 1 to 4 of k²
= 1² + 2² + 3² + 4² = 30
Always check the starting index and ending index. If the index starts at 0, the first substitution must use 0.

11. Exam tips and common mistakes

  • Do not confuse common difference d with common ratio r.
  • Remember the n − 1 in the general-term formulas.
  • Use Tₙ for a single term and Sₙ for a sum.
  • Find the number of terms before using a sum formula if n is not given.
  • Use the correct last term in Sₙ = n(a + l)/2.
  • Check |r| < 1 before calculating a sum to infinity.
  • For sigma notation, substitute every index value, including the endpoints.
  • Show your proof steps rather than writing only the final formula.

1. Inverse functions and general properties

An inverse function reverses the action of the original function. If a function takes an input x and produces an output y, its inverse takes that output and returns the original input.

f⁻¹(f(x)) = x and f(f⁻¹(x)) = x

The symbol f⁻¹(x) means the inverse function. It does not mean 1/f(x).

How to find an inverse

  1. Write the function as y = f(x).
  2. Swap x and y.
  3. Solve the new equation for y.
  4. Write the result as f⁻¹(x).
  5. Check any required domain restrictions.
Example: Find the inverse of y = 3x − 6.

Swap: x = 3y − 6

x + 6 = 3y

Therefore, f⁻¹(x) = (x + 6)/3.

General properties of inverse functions

  • The domain of the inverse equals the range of the original function.
  • The range of the inverse equals the domain of the original function.
  • The graphs reflect in the line y = x.
  • The x- and y-coordinates of corresponding points swap.
  • The x-intercept of one graph corresponds to the y-intercept of its inverse, where those intercepts exist.
  • A function must be one-to-one on its domain to have an inverse that is also a function.
Domain of f⁻¹ = Range of f
Range of f⁻¹ = Domain of f
The horizontal line test helps determine whether a graph is one-to-one. Every horizontal line must intersect the graph at most once.

2. Inverse of a linear function

A non-horizontal straight-line function has an inverse function. The inverse is also a straight line.

f(x) = mx + c, where m ≠ 0
f⁻¹(x) = (x − c)/m
Worked example: Find the inverse of f(x) = 2x + 3.
  1. Write y = 2x + 3.
  2. Swap x and y: x = 2y + 3.
  3. Subtract 3: x − 3 = 2y.
  4. Divide by 2.
f⁻¹(x) = (x − 3)/2

General properties

  • Domain and range are both all real numbers for a non-horizontal straight line.
  • The inverse is a straight line.
  • The inverse's gradient is the reciprocal of the original gradient.
  • The two graphs reflect in y = x.

Checking your answer

If f(2) = 7, then f⁻¹(7) must equal 2. For f(x) = 2x + 3, this works because (7 − 3)/2 = 2.

3. Inverse of a parabola

A full parabola generally fails the horizontal line test. Therefore, its inverse is not a function unless the original domain is restricted to one side of the turning point.

Worked example: Find the inverse of f(x) = (x − 1)² + 2, given x ≥ 1.
  1. Write y = (x − 1)² + 2.
  2. Swap x and y: x = (y − 1)² + 2.
  3. Subtract 2: x − 2 = (y − 1)².
  4. Take square roots: y − 1 = ±√(x − 2).
  5. Because the original domain is x ≥ 1, use the positive branch.
f⁻¹(x) = 1 + √(x − 2)

General properties

  • The turning point (1, 2) becomes (2, 1) on the inverse graph.
  • The original domain is x ≥ 1.
  • The original range is y ≥ 2.
  • The inverse domain is x ≥ 2.
  • The inverse range is y ≥ 1.
  • The inverse graph is a square-root curve.
Important: If the parabola is restricted to x ≤ 1 instead, the inverse becomes f⁻¹(x) = 1 − √(x − 2). Always use the domain restriction in the question to select the correct branch.

4. Exponential functions

An exponential function has the variable in the exponent.

f(x) = aˣ, where a > 0 and a ≠ 1

General properties of y = aˣ

  • Domain: all real numbers.
  • Range: y > 0.
  • Y-intercept: (0, 1).
  • There is no x-intercept.
  • Horizontal asymptote: y = 0.
  • If a > 1, the function is increasing.
  • If 0 < a < 1, the function is decreasing.
Example: For f(x) = 2ˣ:
  • f(0) = 1
  • f(1) = 2
  • f(3) = 8
  • f(−1) = 1/2

Transformations

y = aˣ + q has horizontal asymptote y = q.

The value q shifts the graph up or down. A factor outside the exponential changes its vertical scale.

5. Inverse of an exponential function

The inverse of an exponential function is a logarithmic function.

Worked example: Find the inverse of f(x) = 2ˣ.
  1. Write y = 2ˣ.
  2. Swap x and y: x = 2ʸ.
  3. Express the equation using logarithms: y = log₂(x).
f⁻¹(x) = log₂(x)

General properties

  • Original exponential domain: all real numbers.
  • Original exponential range: y > 0.
  • Inverse logarithmic domain: x > 0.
  • Inverse logarithmic range: all real numbers.
  • The exponential asymptote y = 0 corresponds to the logarithmic asymptote x = 0.
  • The graphs reflect in y = x.

Exponential and logarithmic form

aˣ = y ⇔ logₐ(y) = x

For example, 2³ = 8 is equivalent to log₂(8) = 3.

6. Working with logarithmic functions

A logarithm answers the question: “To what power must the base be raised to obtain this number?”

y = logₐ(x) means aʸ = x

For real logarithms, the base must satisfy a > 0 and a ≠ 1, and the argument must be positive.

General properties of y = logₐ(x)

  • Domain: x > 0.
  • Range: all real numbers.
  • X-intercept: (1, 0).
  • No y-intercept.
  • Vertical asymptote: x = 0.
  • If a > 1, the function is increasing.
  • If 0 < a < 1, the function is decreasing.
Examples:
  • log₂(8) = 3 because 2³ = 8.
  • log₃(9) = 2 because 3² = 9.
  • log₁₀(100) = 2 because 10² = 100.
  • log₅(1) = 0 because 5⁰ = 1.

Solving a logarithmic equation

Solve log₂(x) = 4.

Convert to exponential form: x = 2⁴.

Answer: x = 16.

A logarithm of zero or a negative number is undefined in the real number system. Check that every logarithm's argument is positive when solving equations.

9.Inverse Functions
What is an inverse function?

An inverse function reverses the action of the original function.

If \(f\) changes an input \(x\) into an output \(y\), then \(f^{-1}\) changes that output \(y\) back into the original input \(x\).

Important: \(f^{-1}(x)\) means the inverse function. It does NOT mean \(\frac{1}{f(x)}\).

Notation:

Original function: \(y=f(x)\)

Inverse function: \(y=f^{-1}(x)\)

To find an inverse, interchange \(x\) and \(y\), then make \(y\) the subject.

General properties of inverse functions

Property Original function Inverse function
Input and output Input \(x\), output \(y\) Input \(y\), output \(x\)
Domain and range Domain: allowed \(x\)-values Domain and range interchange
Graphs Graph of \(f(x)\) Reflection of \(f(x)\) in \(y=x\)
Coordinates \((a;b)\) \((b;a)\)
Function test Must be a function Must also be a function on its stated domain
Exam rule: A function must be one-to-one on its domain to have an inverse that is also a function. A horizontal line must not cut its graph more than once.

9.1 Inverse of a Linear Function

A non-horizontal straight-line function has an inverse function. Follow these steps every time.

Worked example 1

Given \(f(x)=3x-6\), determine \(f^{-1}(x)\).

Step 1: Write the equation.

\(y=3x-6\)

Step 2: Interchange \(x\) and \(y\).

\(x=3y-6\)

Step 3: Make \(y\) the subject.

\(x+6=3y\)

\(y=\frac{x+6}{3}\)

Final answer:

\[ f^{-1}(x)=\frac{x+6}{3} \]

Checking your answer

Choose \(x=4\) in the original function:

\(f(4)=3(4)-6=6\)

Now use the output, \(6\), in the inverse:

\(f^{-1}(6)=\frac{6+6}{3}=4\)

We returned to the original input, so the inverse is correct.

9.2 Inverse of a Parabola

A parabola normally fails the horizontal line test because a horizontal line can intersect it twice. Therefore, we restrict its domain to one side of its turning point before finding an inverse function.

Worked example 2

Given \(f(x)=(x-1)^2+2\), where \(x\geq1\), find the inverse.

Step 1: Write the equation.

\(y=(x-1)^2+2\)

Step 2: Interchange \(x\) and \(y\).

\(x=(y-1)^2+2\)

Step 3: Make \(y\) the subject.

\(x-2=(y-1)^2\)

\(\sqrt{x-2}=y-1\)

\(y=1+\sqrt{x-2}\)

We use the positive square root because the original restriction is \(x\geq1\).

Final answer:

\[ f^{-1}(x)=1+\sqrt{x-2},\quad x\geq2 \]

Domain and range of the parabola

Original function Inverse function
Equation \((x-1)^2+2\) \(1+\sqrt{x-2}\)
Domain \(x\geq1\) \(x\geq2\)
Range \(y\geq2\) \(y\geq1\)
Starting point \((1;2)\) \((2;1)\)

Reflection of a restricted parabola

The inverse graph is obtained by swapping every coordinate \((x;y)\) to \((y;x)\). Use the equations and table above for exact values.

Common mistake: Do not simply write a square root and forget the domain restriction. State the inverse's domain as well as its equation.

9.3 Inverse of an Exponential Function

Exponential and logarithmic functions are inverses of each other.

Worked example 3

Given \(f(x)=2^x\), find the inverse.

Step 1: Write \(y=2^x\).

Step 2: Interchange \(x\) and \(y\): \(x=2^y\).

Step 3: Express this in logarithmic form: \(y=\log_2 x\).

Answer:

\[ f^{-1}(x)=\log_2 x,\quad x>0 \]

A logarithm answers the question: to what power must the base be raised to get a given number?

9.5 Laws of Logarithms

Product law

\[ \log_a(MN)=\log_a M+\log_a N \]

Quotient law

\[ \log_a\left(\frac{M}{N}\right)=\log_a M-\log_a N \]

Power law

\[ \log_a(M^k)=k\log_a M \]

Special values

\[ \log_a1=0,\qquad \log_a a=1 \]

Change of base

\[ \log_a M=\frac{\log M}{\log a} \]

Worked example 4: Simplify

\(\log_2 8+\log_2 4\)

\(=3+2\)

\(=5\)

Worked example 5: Expand

\(\log_3(9x^2)\), where \(x>0\).

\(=\log_3 9+\log_3 x^2\)

\(=2+2\log_3 x\)

Do not make this mistake:

\(\log_a(M+N)\ne\log_a M+\log_a N\).

The product law applies to multiplication, not addition.

Finance, Growth and Decay

Compound interest is calculated on the original amount and on interest already accumulated.
A = P(1 + i)ⁿ
  • A = accumulated amount
  • P = initial amount or principal
  • i = interest rate per period as a decimal
  • n = number of periods
R1 000 invested at 10% per year for 2 years: A = 1 000(1.10)² = R1 210.

Differential Calculus

A derivative measures the instantaneous rate of change of a function and gives the gradient of the tangent.
If y = xⁿ, then dy/dx = nxⁿ⁻¹
y = 3x² + 4x − 1 → dy/dx = 6x + 4.
  • Differentiate powers of x.
  • Find stationary points by setting dy/dx = 0.
  • Use the original function to calculate the y-coordinate.
  • Determine whether a stationary point is a maximum or minimum.
The derivative of a constant is zero.

Probability

Probability measures how likely an event is to occur. 0 means impossible; 1 means certain.
P(A) = favourable outcomes / total equally likely outcomes
For a fair six-sided die, P(rolling a 4) = 1/6.
  • Complement: P(not A) = 1 − P(A).
  • Mutually exclusive events cannot occur together.
  • Independent events do not change each other's probabilities.
Check whether outcomes are equally likely before using the simple fraction formula.

Statistics

Statistics involves collecting, organising, analysing and interpreting data.
  • Mean: sum of observations ÷ number of observations.
  • Median: middle observation after arranging data in order.
  • Mode: most frequent value.
  • Range: maximum − minimum.
  • Quartiles: values dividing ordered data into four parts.
  • Standard deviation: measures spread around the mean.
Arrange data in ascending order before finding the median or quartiles.

Analytical Geometry

Analytical geometry uses coordinates and algebra to investigate geometric relationships.
Gradient: m = (y₂ − y₁)/(x₂ − x₁)
Distance: AB = √[(x₂ − x₁)² + (y₂ − y₁)²]
Midpoint: M = ((x₁ + x₂)/2, (y₁ + y₂)/2)
Subtract coordinates in the same order in the numerator and denominator when calculating a gradient.

Trigonometry

Trigonometry studies relationships between angles and trigonometric ratios.
sin²θ + cos²θ = 1
tan θ = sin θ / cos θ, when cos θ ≠ 0
sin(A ± B) = sin A cos B ± cos A sin B
Check the specified interval when solving trigonometric equations.
