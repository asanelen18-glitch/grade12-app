What is algebra?

Algebra uses letters and symbols to represent numbers and relationships.

1. Algebraic expressions and like terms

An algebraic expression contains numbers, variables and operations.

Variable: a letter representing a number.

Coefficient: the number multiplying a variable.

Constant: a number without a variable.

Term: a part separated by plus or minus signs.

3x + 5
Simplify 4x + 3x − 2 + 5.
(4x + 3x) + (−2 + 5) = 7x + 3
Simplify 5a + 2b − 3a + 4b.
2a + 6b
Combine like terms only. For example, 2x and 3x² are unlike terms.

2. Multiplying and expanding brackets

Expand (x + 2)(x + 3).
= x² + 3x + 2x + 6
= x² + 5x + 6

Learn to recognise patterns, calculate general terms, find the position of a term, and calculate sums.

Sequence: an ordered list of numbers arranged according to a rule.

Series: the sum of terms in a sequence.

Sequence: 2, 5, 8, 11, …
Series: 2 + 5 + 8 + 11 + …

3. Arithmetic sequences

An arithmetic sequence has a constant difference between consecutive terms.
Tₙ = a + (n − 1)d
Find the 20th term of 4, 9, 14, 19, …

a = 4, d = 5, n = 20.

T₂₀ = 4 + (20 − 1)(5)
T₂₀ = 99
Which term of 7, 11, 15, 19, … is 63?
63 = 7 + (n − 1)4
56 = 4(n − 1) → n = 15

4. Arithmetic series

Sₙ = n/2 [2a + (n − 1)d]
Sₙ = n/2 (a + l)
Find the sum of the first 10 terms of 2, 5, 8, 11, …
S₁₀ = 10/2 [2(2) + 9(3)]
= 5(31) = 155

5. Geometric sequences

A geometric sequence has a constant ratio between consecutive non-zero terms.
Tₙ = arⁿ⁻¹
Find the 6th term of 2, 6, 18, 54, …
T₆ = 2(3)⁵ = 486
Find the general term of 80, 40, 20, 10, …
Tₙ = 80(½)ⁿ⁻¹

6. Finite geometric series

Sₙ = a(rⁿ − 1)/(r − 1), r ≠ 1
Sₙ = a(1 − rⁿ)/(1 − r), r ≠ 1
Find the sum of the first four terms of 2, 6, 18, 54, …
S₄ = 2(3⁴ − 1)/(3 − 1) = 80

7. Infinite geometric series

An infinite geometric series has a finite sum only when |r| < 1.
S∞ = a/(1 − r)
Find the sum of 12 + 6 + 3 + 1.5 + …
S∞ = 12/(1 − ½) = 24
Do not use the infinite-sum formula when |r| ≥ 1.

9. Exam tips

  • Do not confuse common difference d with common ratio r.
  • Remember the n − 1 in the nth-term formulas.
  • Use a T formula for one term and an S formula for a sum.
  • Check the condition |r| < 1 before calculating an infinite sum.
  • Show your substitution and calculation steps.

📈 Functions and Graphs

This chapter explains how to identify, interpret, sketch and compare the main functions studied in Grade 12 Mathematics.

What is a function?

A function is a rule that assigns exactly one output y to each allowed input x.

Input value x
↓
Apply the function rule
↓
Output value y = f(x)

For example, if f(x) = 2x + 1, then f(3) = 2(3) + 1 = 7.

1. Important graph vocabulary

TermMeaning
Function notationf(x) or y represents the output for an input x.

RangeAll possible output values, usually y-values.
x-interceptWhere the graph meets the x-axis; y = 0.
y-interceptWhere the graph meets the y-axis; x = 0.
Turning pointA maximum or minimum point on a curve such as a parabola.

2. Function notation and calculating outputs

The expression f(x) means the output of the function f for the input x. It does not mean f multiplied by x.
Given f(x) = 3x − 4, calculate f(5).
f(5) = 3(5) − 4
f(5) = 15 − 4 = 11
Given g(x) = x² + 2x, calculate g(−3).
g(−3) = (−3)² + 2(−3)
= 9 − 6 = 3
When substituting a negative number, put it in brackets before squaring or multiplying.

3. The straight-line function

The general equation of a straight line is:
y = mx + c
  • m: gradient or slope.
  • c: y-intercept.
A positive gradient rises from left to right. A negative gradient falls from left to right.

A positive gradient rises from left to right.

Finding the gradient

m = (y₂ − y₁)/(x₂ − x₁)
Find the gradient through A(1, 3) and B(4, 9).
m = (9 − 3)/(4 − 1) = 6/3 = 2

Finding the equation of a straight line

A line has gradient 2 and passes through (1, 3). Find its equation.

Start with y = mx + c.

3 = 2(1) + c
c = 1

Answer:

y = 2x + 1

Finding intercepts

For y = 2x − 6:
  • For the y-intercept, set x = 0: y = −6. The point is (0, −6).
  • For the x-intercept, set y = 0: 0 = 2x − 6, so x = 3. The point is (3, 0).

4. The parabola (quadratic function)

The general form is:
y = ax² + bx + c, where a ≠ 0
  • If a > 0, the parabola opens upwards.
  • If a < 0, the parabola opens downwards.
  • The y-intercept is (0, c).
  • The axis of symmetry is x = −b/(2a).
  • The turning point lies on the axis of symmetry.

An upward-opening parabola has a minimum turning point.

Finding the turning point

x-coordinate: x = −b/(2a)

Substitute that x-value into the original function to calculate the y-coordinate.

Worked example: Find the turning point of y = x² − 4x + 3.

a = 1, b = −4, c = 3.

x = −(−4)/(2 × 1) = 2
y = 2² − 4(2) + 3 = −1

Turning point: (2, −1).

Axis of symmetry: x = 2.

Since a = 1 is positive, the parabola opens upwards.

Finding the x-intercepts by factorisation

Find the x-intercepts of y = x² − 4x + 3.

Set y = 0.

x² − 4x + 3 = 0
(x − 1)(x − 3) = 0
x = 1 or x = 3

The intercepts are (1, 0) and (3, 0).

Finding the range of a parabola

For y = (x − 2)² − 1, the turning point is (2, −1). The graph opens upwards, so −1 is the minimum y-value.
Range: y ≥ −1

5. The hyperbola

A common Grade 12 hyperbola has the form:
y = a/x + q, where a ≠ 0
  • The vertical asymptote is x = 0.
  • The horizontal asymptote is y = q.
  • The value of a affects the direction and shape.
  • The value of q shifts the graph vertically.

The dashed lines show the asymptotes.

For y = 6/x + 2:
  • Vertical asymptote: x = 0.
  • Horizontal asymptote: y = 2.
  • For x = 3, y = 6/3 + 2 = 4, so (3, 4) is on the graph.
  • For x = −2, y = 6/(−2) + 2 = −1, so (−2, −1) is on the graph.

Intercepts of a hyperbola

For y = 6/x + 2:

For the x-intercept, set y = 0.

0 = 6/x + 2 → x = −3

The x-intercept is (−3, 0). There is no y-intercept because x cannot equal zero.

6. The exponential function

A common exponential function has the form:
y = abˣ + q

For the usual exponential graph, a ≠ 0, b > 0 and b ≠ 1.

  • If b > 1 and a > 0, the graph increases.
  • If 0 < b < 1 and a > 0, the graph decreases.
  • The horizontal asymptote is y = q.
  • The y-intercept is (0, a + q).

An increasing exponential curve approaches its horizontal asymptote on one side.

For y = 2ˣ:
x−2−1012
y = 2ˣ¼½124

The graph passes through (0, 1), increases from left to right and has horizontal asymptote y = 0.

8. Transformations of graphs

Transformations move, reflect or stretch an original graph. Learn what each change does.
New functionTransformation
y = f(x) + qMove vertically up q if q > 0; down if q < 0.
y = f(x − p)Move horizontally right p if p > 0.
y = −f(x)Reflect in the x-axis.
y = f(−x)Reflect in the y-axis.
y = af(x)Vertical stretch or compression; negative a also reflects in the x-axis.
Compare y = x² and y = (x − 3)² + 2.
  • The graph shifts 3 units to the right.
  • The graph shifts 2 units upwards.
  • The new turning point is (3, 2).
  • The axis of symmetry is x = 3.
Be careful with horizontal shifts: (x − 3) moves right by 3, while (x + 3) moves left by 3.

9. Intersections of graphs

At an intersection, two graphs have the same x-value and the same y-value. Set their equations equal to each other to find the intersection coordinates.
Find the intersection of y = x + 1 and y = 2x − 2.
x + 1 = 2x − 2
x = 3

Substitute x = 3 into either equation:

y = 3 + 1 = 4

Intersection: (3, 4).

11. Exam tips and common mistakes

  • For x-intercepts, set y = 0.
  • For the y-intercept, set x = 0.
  • Do not confuse the turning point with an intercept.
  • Always state the equation of the axis of symmetry for a parabola when requested.
  • Label asymptotes clearly and use dashed lines in a sketch where appropriate.
  • For a hyperbola y = a/x + q, remember x = 0 is excluded from its domain.
  • For an exponential function y = abˣ + q, remember the horizontal asymptote y = q.
  • When asked to sketch, show intercepts, turning points, asymptotes and the general shape.
  • When solving intersections, substitute back to find both coordinates.

Finance, Growth and Decay

Compound interest is calculated on the original amount and on interest already accumulated.
A = P(1 + i)ⁿ
  • A = accumulated amount
  • P = initial amount or principal
  • i = interest rate per period as a decimal
  • n = number of periods
R1 000 invested at 10% per year for 2 years: A = 1 000(1.10)² = R1 210.
Convert 8% to 0.08 before substituting. Match the interest rate and number of periods.

Differential Calculus

A derivative measures the instantaneous rate of change of a function and gives the gradient of the tangent.
If y = xⁿ, then dy/dx = nxⁿ⁻¹
Example: y = 3x² + 4x − 1 → dy/dx = 6x + 4.
  • Differentiate powers of x.
  • Find stationary points by setting dy/dx = 0.
  • Use the original function to calculate the y-coordinate.
  • Determine whether a stationary point is a maximum or minimum.
The derivative of a constant is zero.

Probability

Probability measures how likely an event is to occur. 0 means impossible; 1 means certain.
P(A) = favourable outcomes / total equally likely outcomes
For a fair six-sided die, P(rolling a 4) = 1/6.
  • Complement: P(not A) = 1 − P(A).
  • Mutually exclusive events cannot occur together.
  • Independent events do not change each other's probabilities.
Check whether outcomes are equally likely before using the simple fraction formula.

Statistics

Statistics involves collecting, organising, analysing and interpreting data.
  • Mean: sum of observations ÷ number of observations.
  • Median: middle observation after arranging data in order.
  • Mode: most frequent value.
  • Range: maximum − minimum.
  • Quartiles: values dividing ordered data into four parts.
  • Standard deviation: measures spread around the mean.
Arrange data in ascending order before finding the median or quartiles.

Analytical Geometry

Analytical geometry uses coordinates and algebra to investigate geometric relationships.
Gradient: m = (y₂ − y₁)/(x₂ − x₁)
Distance: AB = √[(x₂ − x₁)² + (y₂ − y₁)²]
Midpoint: M = ((x₁ + x₂)/2, (y₁ + y₂)/2)
Subtract coordinates in the same order in the numerator and denominator when calculating a gradient.

Trigonometry

Trigonometry studies relationships between angles and trigonometric ratios.
sin²θ + cos²θ = 1
tan θ = sin θ / cos θ, when cos θ ≠ 0
sin(A ± B) = sin A cos B ± cos A sin B
Check the specified interval when solving trigonometric equations.
